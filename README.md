# N3uralia360 — Earlier Web Implementation

This repository is part of the engineering history of **N3uralia360**, N3uralia's immersive and spatial-media vertical.

The current product and portfolio surface is:

**[n3uralia360.art](https://n3uralia360.art)**

This repository should be understood as an earlier implementation focused on a 360° image marketplace/e-commerce model. It is preserved because it contributed product, media, storage and delivery patterns to the current N3uralia360 line, but it is **not the canonical description of the product today**.

---

## Current N3uralia360 direction

N3uralia360 works across:

- immersive worlds and spatial storytelling;
- fulldome media and large-format experiences;
- VR and interactive cultural environments;
- heritage and museum experiences;
- AI-assisted visual production for spherical and panoramic media.

The product direction has moved beyond a marketplace-only model toward immersive-media systems and experiences.

---

## What this repository contains

The implementation includes patterns for:

- 360° image browsing and collections;
- authentication and user profiles;
- shopping/cart/order flows;
- protected downloads;
- media storage and delivery;
- administrative content management;
- responsive Next.js application surfaces.

These are historical implementation details, not a claim that every component remains part of the current N3uralia360 production stack.

---

## Technology

This generation was built with Next.js, TypeScript, Supabase/PostgreSQL and cloud object storage/deployment services.

Deployment credentials, customer information and private media must never be committed to the repository.
